Tracefield — guide

1 · Pin

Drop PNG / JPG / PDF files anywhere (or paste). Each page becomes a scan card. With auto-digitize on, a map card appears next to it, tied with a red string.

2 · Calibrate

Double-click a scan, or press the wand. Drag the 4 handles onto the axes (top of Y, origin, end of X). Tilted phone photos are perspective-corrected. Name the axes and ranges, then save. The first saved map becomes the template for every later import.

3 · Clean up

Erase noise brushes away digits and notes. Pick colour ignores an ink. Fragments lets you move pieces between lines. Trace draws a line by hand. Lines with the same name are compared as the same series.

4 · Compare

Select maps and press G, or drag a map onto a lens. Modes: Overlay, Ridge (one row per map), Heat (density of all lines), Δ Deviation (each line minus its group average).

Average merges lines per key, participant, test or tag, with ±SD or min–max bands. Consensus morphs every line toward its average. Quantize averages lines into X steps and snaps Y to levels (e.g. a 5-point scale).

Colour by any field and edit the colour codes in the legend. Filter by tag, reorder layers, stack the perspective-corrected scans underneath, and read the insights and similarity matrix.

5 · Play

▶ sweeps a playhead along X. 🔊 turns each line into a voice — pitch follows the value. Hover with sound on to scrub. Edit a map's lines with the brush (sculpt, redraw, add, cut).

6 · Map

Use the background button at the top left to swap the pinboard for streets, satellite or the Earth globe, or Google Maps and Google Earth 3D with your API key.

Drop a sound file on the map to make a point, or outline a region. Drag graphs from the library to pin them, then link anything with arrows, lines or flows. Link a graph to a sound and its lines can drive tempo, emphasis, brightness and space as it plays.

7 · Listen

Soundwalk fades each place in as you move near it. Journey flies along your arrows, stop by stop. Exhibit hides the tools for visitors. Hold Space to flip between the recording and how it felt.

Google Maps & Earth

Google's backgrounds need your own API key. It stays in this browser and is never written to project exports.

  1. In the Google Cloud console, create a project with billing enabled.
  2. Enable the Maps JavaScript API, the Map Tiles API (for Earth 3D) and the Geocoding API (for search).
  3. Create an API key and restrict it to your site's address.

A key restricted to a web address won't work on a page opened straight from a file, so serve the folder from that address. Map usage is billed by Google. The free backgrounds need no key.
